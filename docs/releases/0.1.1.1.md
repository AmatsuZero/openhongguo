# Release 0.1.1.1

## Changes

- **Discover `PageSize`**: `DiscoverOptions.PageSize` sets `bookmall/cell/change` `limit` (default 20, max 50).
- Discover feed cursors (`d1.…`) now include optional `limit` for consistent pagination.
- CLI: `ohg discover --page-size N` (reuses existing global `--page-size` flag).

## Publish (AmatsuZero/openhongguo) — CI only

No local Go / gomobile. Same flow as `xcf-v0.1.1`:

1. `main` green (CI + contract).
2. `git tag xcf-v0.1.1.1 && git push origin xcf-v0.1.1.1` — [`.github/workflows/xcf.yml`](../.github/workflows/xcf.yml) builds zip, publishes release, commits checksum to `main`.
3. Tag semver on the CI commit if needed: `git tag v0.1.1.1 && git push origin v0.1.1.1`.
4. CrawlerBot: `hongguo/swift/Package.swift` → `from: "0.1.1.1"` (checksum already in upstream `Package.swift`).
