# 0.1.5

- 漫画正文使用独立的严格 ID 解码：保留字符串和无精度损失的十进制整数，拒绝对象、数组、布尔、小数、指数和负数；不改变其他旧接口的宽松解析行为。
- Node/WASM transport 响应 Go context 的取消与截止时间，并把 `AbortSignal` 传给自定义/默认 transport；即使自定义 transport 不响应取消，SDK 也会及时返回，晚到 Promise 不调用已释放的 Go 回调。
- 默认 Node transport 的 `timeoutMs` 同时限制完整请求时长，持续流式响应不能无限延长等待；取消会关闭底层请求。
- 增加严格 ID、WASM 取消/晚到响应、Node 慢流与请求关闭回归；Node 20/22 CI 执行 WASM 取消测试。保持现有 API 和 macOS 12 / iOS 13 最低版本。
