# 0.1.4

- 新增 `Client.GetComicReader(ctx, bookID)`，读取官方 Web 漫画页公开的章节与图片。不会注册设备或发送账号/游客凭据。
- 返回 `ComicReader`、`ComicChapter`、`ComicPage`，保留官网顺序、图片尺寸、公开数量和来源地址。`next_episode_id` 仅是后续章节标识，不代表可读或付费。
- 同步 Swift、Kotlin、Node、React Native、Flutter 的 `getComicReader` 与可选 `webOrigin`。
- 公开 HTML 请求拒绝重定向，限制响应为 4 MiB，校验书号、正文和官方 HTTPS 图片地址；零可读返回空章节，损坏正文返回显式错误。
- macOS 12 / iOS 13 最低版本保持不变；Go 核心二进制由 `xcf` GitHub Actions 发布。

本地验证：Go 全套测试、`go vet`、mobile core 测试、Swift 9 项、Node 8 项、React Native 7 项通过；真实 Swift serve 消费端已加载示例漫画首话 40 张图片。Flutter/Android 运行检查由 CI 执行，不以生成代码或本地 Swift 通过替代。
